# Cs2-Player-Dashboard
A full-stack web dashboard for tracking Counter-Strike 2 player statistics, including kills, deaths, match history, and authentication.

Built with:

- Frontend: React, Vite, TypeScript

- Backend: FastAPI (Python)

- Database: SQLite


Features

- CS2 Server plugin to record player match data

- Player authentication using Steam API (login / register)

- View extensive player stats including weapons used

- Dashboard UI with banner and profile image

- REST API backend

- CORS-enabled communication between frontend and backend


Requirements

- Active cs2 server using CSSharp plugin 

- Node.js 18+ , Python 3.10+ , pip , npm

Development Plan 

- Change Database architecture from Docker Image to in-dashboard SQL db

- Add Docker integration for server deployment
